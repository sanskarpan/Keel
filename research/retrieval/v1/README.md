# Synthetic retrieval evaluation seed v1

This is a small contract fixture, not a benchmark or a representation of customer documents. Every document and query was authored for this repository, contains no personal data, and is released under CC0-1.0. Labels and rationales were authored alongside the synthetic examples; no model output generated these labels. This seed has not had an independent annotator disagreement study.

`corpus.json` contains versioned source text, train/dev/holdout queries, graded relevant and hard-negative judgments with source byte spans, and explicit cross-tenant denial fixtures. All documents are synthetic, published examples. Dataset and manifest bytes are pinned in `SHA256SUMS`; the adjacent `.sha256` files are consumed by `keel-corpus-lint`.

The partitions deliberately use distinct queries and source versions. The linter rejects exact or >=0.80 Jaccard overlap of normalized token bigrams across query partitions, repeated source versions across partitions, references to unpublished/missing sources, invalid UTF-8/offsets, hidden-scope labels, empty/no-answer mistakes, and duplicate identities. The small corpus only exercises the contract; it is far too small to support recall, precision, latency, tenant-isolation, or production-quality claims.

`reference-results.json` is generated by `make retrieval-eval`; CI regenerates it in a temporary file and requires a byte-for-byte match. It records evaluator/model/corpus identities and per-query top-five BM25 scores. For this deliberately easy seed, all 7 answerable queries rank their sole positive source first (MRR@5, nDCG@5 and recall@5 are each 1.0); both no-answer queries produce a positive lexical match (0/2 true negatives). These tiny authored examples are a reproducibility check, not evidence of general search quality. The no-answer failures are kept visible rather than tuned away.

Annotation guidance: each query represents one explicit information need; direct evidence receives grade 3, partially useful evidence grade 1 or 2 when present, and non-answering same-scope sources grade 0. A no-answer query has no positive labels. Rationale text records why the source supports or fails to support the query. Source citations use zero-based UTF-8 byte spans with exclusive end offsets. Changes require a separate label review plus review of license, synthetic/PII status, access scope, offsets, split leakage, and digest changes together.
