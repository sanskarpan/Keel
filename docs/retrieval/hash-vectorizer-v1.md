# Evaluation-only hash vectorizer v1

`keel.hash-vectorizer.v1` is a deterministic, provider-neutral fixture identity for validating model manifests and corpus plumbing. Its proposed mapping is analyzer terms to signed fixed-width hash buckets followed by L2 normalization. This repository does not implement or execute that vectorizer. It is not a semantic model, has no learned weights or external model artifact, and must not be configured for production search, quality claims, or customer data. The manifest digest pins this specification as provenance for the fixture identity; changing the proposed algorithm or analyzer requires a new model ID and corpus build.

The initial K3.1 corpus manifest records this fixture solely to exercise dimensions, tokenizer binding, normalization, distance, and immutable build identity. No vectors are generated by K3.1. K3.3 adds a different, synthetic 3D mechanics fixture to test storage and ANN behavior; it does not implement this proposed vectorizer or qualify any semantic model. A real model requires a separately reviewed immutable manifest and parallel index; vectors from different identities are never compatible.
