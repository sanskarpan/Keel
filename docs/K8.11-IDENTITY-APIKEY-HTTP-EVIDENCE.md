# K8.11/K8.2 slice 13: API-key HTTP surface

Related to #70 and the K8.2 track. Storage proved the key lifecycle; this
slice serves it on four unmounted routes with the session principal as the
only actor. No route is mounted.

## Contract

- `internal/auth/httpapi/apikeys.go` (same hardening: `8 KiB` bodies,
  `DisallowUnknownFields`, `problem+json`, security headers, wire shown
  once and never logged):
  - `POST /v1/auth/service-principals` `{org_id,name}` (Bearer
    owner/admin): `201 {service_principal_id,org_id}`, `403`,
    `400`.
  - `POST /v1/auth/service-principals/{sp}/keys` `{expires_at?}`
    (Bearer owner/admin of the owning org): `201
    {key_id,api_key,prefix}`, `403`, `404` for missing principals,
    `400` for bad ids/expiry.
  - `POST .../keys/{key_id}/revoke` → `204`, `403`, `404`.
  - `POST .../{sp}/disable` → `204`, `403`, `404`.
  - `apiKeyIdentity` helper resolves one bearer key for future
    middleware: only `valid` yields an identity.
- Migration `0077_identity_api_key_actor_auth` (designed in, applied
  with this slice): issue/revoke/disable take the session actor and
  require owner/admin membership in the key's organization; the
  capability-only originals are dropped. Without it any capability
  holder could mint or kill any org's keys.

## Verified

- `go vet ./internal/auth/...` and `gofmt` clean;
  `go test ./internal/auth/...` pass, including mapping groups for
  all four routes plus the helper (valid/revoked/unknown/error).
- Migrations applied live through the runner (`0077` ledgered).
- In-container against real capability roles:
  `--- PASS: TestHTTPAPIKeysLifecycleAgainstPostgres` — stranger
  create `403`, create `201`, issue `201` with resolving valid
  identity, stranger revoke `403`, revoke `204` with stored `revoked`,
  disable `204`. All five HTTP suites pass in the same run.

## Limits

- No routes mounted; verification middleware is a helper, not wired
  into any gateway.
- No key listing, naming, per-key scopes, usage metering, expiry
  rotation policy or audit trail.
