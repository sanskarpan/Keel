# K7.1 slice: Modal deployment scaffold

Issue #462 (K7.1 partial, parents #48/#51). This slice adds an unqualified Modal app
definition for the webhook worker and operator API. No infrastructure is provisioned, no
secrets are created, and nothing has run against Modal.

## Contract

- `deploy/modal/keel.py` builds the `keel` binary from a digest-pinned Go 1.27 image,
  wires `keel-operator`/`keel-webhook` secrets, exposes the operator API as a web server
  endpoint, runs the worker loop as a persistent function (`min_containers=1`, 12-hour
  restart cadence; lease epochs make restarts safe), and provides a one-shot migrate job.
- `deploy/modal/README.md` documents secret creation (fresh values only), deploy/migrate
  commands, and the external managed-Postgres prerequisite.
- Definitions import cleanly against the installed Modal SDK (1.6.3), which caught and fixed
  one API drift (`keep_warm` renamed to `min_containers`).

## Limits

Scaffold only: no deploy, no secret values, no managed database, no Kafka/Redis/Temporal
roles, no production qualification. Digest must be re-checked before production use.

## Verification

- `python -m py_compile` and a decorator-resolving module import against modal 1.6.3.
- Linux CI does not execute Modal; this file is outside the Go build.
