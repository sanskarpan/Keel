# K6.4 slice: reconciliation metrics

Issue #425 (parent #49, checklist item K6.4). PR #426 merged as
`fef833763965706f47a53b55bea4c7a289e29b71`; contract CI #681 passed on reviewed head
`8a2b9d340cab6997686b9f15bafc1f4156c2210b`. This slice adds content-free reconciliation
counters to the existing delivery metrics recorder, fed by a nil-safe store observer hook. No
migration was needed.

## Contract

- `Recorder.ObserveReconciliationPlan/Repair` accumulate plans, scanned/gap/missing counts and
  repairs, repaired/skipped counts, exposed as seven new fixed counter series with no labels.
  The label-surface assertion caps labeled series at the six existing outcome series.
- `postgres.Store.SetReconciliationObserver` registers an optional observer fired by the plan
  and repair paths only after success; nil (the default) disables observation without changing
  existing callers or constructors.
- Coverage includes series rendering, nil-recorder inertness, hook firing with exact counts,
  observer clearing, and the full existing plan/repair suites with the hook unset.

## Limits

No live runtime wires the hook yet; values are process-local and reset on restart. No alert
rules, dashboards, production scrape, scheduler integration, UI or provider observation.
