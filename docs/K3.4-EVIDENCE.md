# K3.4 hybrid retrieval evidence

## Delivered scope

PR [#127](https://github.com/sanskarpan/Keel/pull/127) closes issue [#27](https://github.com/sanskarpan/Keel/issues/27). `internal/retrieval/hybrid` adds a pure Go contract for combining K3.2 lexical and K3.3 vector ranks. Its fixed `rrf-v1` policy uses equal source weights and reciprocal-rank constant 60; source score magnitudes are not mixed. Each source is limited to 500 candidates and output top-k to 100. Fusion validates trusted tenant/cohort scope, exact vector-to-lexical build/generation provenance, source uniqueness, immutable citation equality and deterministic tie ordering.

The result contract distinguishes complete, degraded and unavailable states for partial/missing sources, underfill, no candidates, reranker skip/failure and citation suppression. The optional reranker accepts only citation-resolved candidates, at most 50, with 8 KiB per excerpt, 64 KiB aggregate and a context deadline no longer than 500 ms. It must return a permutation of supplied chunk IDs. Failure preserves fused order and marks degraded.

Before any excerpt may be reranked or returned, `ResolveCitations` requires an injected resolver to recheck live authorization/withdrawal and match immutable version/range/digest identity. Unauthorized or mismatched candidates are suppressed; if current authorization cannot be checked, the result fails closed. This phase supplies the interface and tests, not the authoritative source/ACL adapter.

Unit tests cover exact RRF scores/ties, scope and generation fencing, duplicate/conflicting citations, partial/all-source outages, missing-source degradation, reranker candidate and byte caps, cancellation deadline, malformed/foreign reranker IDs, safe fused-order fallback, citation authorization suppression, digest mismatch and fail-closed resolver failure.

## Boundaries and follow-up

There is no customer-serving API, production reranker provider, source-text fetcher, authoritative ACL/withdrawal resolver, live revocation race qualification, semantic quality evaluation or capacity claim. The fake resolver tests only the contract. Do not mount a route or return search results to customers until K3.5 supplies the authoritative current-authorization/withdrawal adapter, cache/cleanup semantics and adversarial race tests. Any future external reranker must enforce its immutable tokenizer/model-specific token limit; this core enforces generic byte bounds only.
