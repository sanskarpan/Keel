# K6.3 slice: one signed delivery attempt

Issue #356 (parent #48, checklist item K6.3). PR #357 merged as `bd12ea51daae9d0572356835649dbf923d0fff69`; contract CI #588 passed on reviewed head `484078cc608527f945ba880a084dcd53efc20787`. This slice adds the execution step between a
lease and the attempt ledger: sign the exact payload, POST it through the SSRF-safe egress client,
classify the result and discard the receiver body. It does not lease, fetch events, resolve
endpoints, apply the breaker, schedule the next retry or run a worker loop.

## Inputs and bounds

`AttemptRequest` carries the lease's delivery, the active endpoint revision resolved from the
registry, the fresh attempt ID and attempt number, the exact body bytes and the signing time.

| Bound | Value | Behavior |
| --- | --- | --- |
| Body | 1 byte-1 MiB | Empty or oversized bodies are rejected before signing |
| Response drain | 64 KiB | The receiver body is drained only to release the connection; it is never returned or stored |
| Attempt number | 1-1000 | Out-of-range attempt counters are rejected |
| Attempt ID | 8-64 `[A-Za-z0-9_-]` | Fresh per attempt, validated against the wire contract |
| Signing time | nonzero | The caller supplies the clock; the signature timestamp is that value |

The endpoint must be `active` and agree with the delivery on tenant, endpoint ID and subscription
revision. The signing keyring must hold the endpoint's key reference. Any disagreement is a
data-integrity error: nothing is signed, sent or recorded, so a stale registry row cannot silently
deliver an event to the wrong endpoint revision under a rotated key.

## Wire contract

The executor reuses the K6.2 `Keyring.Prepare`, so the signature covers the decimal timestamp and
the exact body bytes, with the key ID and attempt ID in `Keel-Signature`,
`Keel-Event-Id`, `Keel-Delivery-Id` and `Keel-Attempt-Id`. The request is a POST with
`Content-Type: application/json` and `User-Agent: keel-webhook/1`.

The destination is the endpoint's registered HTTPS URL, not a caller-supplied string. It is checked
against the static egress rules before sending, and the egress transport resolves and vets every
address on the dial. The client never uses environment proxies, requires TLS 1.2 or newer, follows
no redirect by default and re-validates any hop the policy would allow.

## Failure handling

| Failure | Recorded outcome |
| --- | --- |
| 2xx | delivered |
| 408, 425, 429, 5xx | retryable |
| other 4xx, unexpected 1xx/3xx | permanent |
| DNS resolution, timeout, connection reset, TLS failure | retryable |
| Egress policy denial at dial time | permanent |

Send-time failures do not return an error carrying the request URL. Go's transport errors include
the destination, which may embed a receiver token, so the executor maps the error to an outcome and
returns nothing from the exchange. Invalid input, a missing key, a static URL denial or a
delivery/endpoint mismatch are returned as errors because they must not consume an attempt.

## What is still missing

The executor performs no persistence and no retry decision. The caller maps its outcome into the
existing `AttemptResult` and uses the retry scheduler for `NextAttemptAt`. It does not load or save
the endpoint breaker; enforcing breaker admission and recording its observation is the worker
slice. Event payload retrieval (added separately by #364), key storage/KMS, lease orchestration,
tenant quotas and metrics also remain open.

## Coverage

Tests use a TLS receiver test double with an injected resolver and dialer, so the real signer,
transport, header rendering and address vetting run against a local server. They verify the
signature, identity headers, content type, user agent and exact body; delivered, retryable and
permanent status classes; redirect refusal; a closed-server transport failure; a private DNS answer
denied as permanent; and rejection of mismatched tenant/endpoint/revision, inactive endpoints,
HTTP or private URLs, mismatched keys, invalid attempt IDs/numbers, empty or oversized bodies and a
zero signing time, with no request sent for any rejected attempt.
