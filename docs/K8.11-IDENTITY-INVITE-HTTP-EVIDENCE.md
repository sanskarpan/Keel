# K8.11/K8.2 slice 11: invite, transfer and switch HTTP surface

Related to #70 and the K8.1/K8.2 tracks. Storage proved the state machine;
this slice serves it: invite by email, accept by token, immediate owner
transfer and per-session org switch on four unmounted routes. No route is
mounted.

## Contract

- `internal/auth/httpapi/invites.go` (same hardening: `8 KiB` bodies,
  `DisallowUnknownFields`, `problem+json`, security headers):
  - `POST /v1/auth/organizations/{org_id}/invites` `{email,role}`
    (Bearer owner/admin): `201 {invite_id}`, `403` for non-owners/admins,
    `409 already_member`, `400` for bad email/role/org id. The token is
    delivered via the reset sender and never appears in the response.
  - `POST /v1/auth/invites/accept` `{token}` (Bearer matching session):
    `200 {org_id}`, `404` unknown, `409 invite_reuse`,
    `410 invite_expired`, `403` mismatch/inactive, `409 already_member`.
  - `POST /v1/auth/organizations/{org_id}/transfer` `{principal_id}`
    (Bearer owner): `204` on transfer including self-transfer no-op,
    `403` for non-owners, `404` for outsiders.
  - `POST /v1/auth/sessions/switch` `{org_id}` (Bearer live session):
    `200 {org_id}`, `401` for dead sessions, `403` for non-members,
    `400` for bad ids.
- The HTTP invite TTL is fixed at 24 h (inside the 1 h–7 d storage
  window); custom windows stay a repository-level capability.

## Verified

- `go vet ./internal/auth/...` and `gofmt` clean;
  `go test ./internal/auth/...` pass, including mapping groups for all
  four routes (actor threading asserted on success paths).
- In-container against real capability roles:
  `--- PASS: TestHTTPInviteTransferAndSwitchAgainstPostgres` — invite
  `201` with sender capture, accept `200`, spent-token reuse `409`,
  transfer `204` then demoted `403`, switch `200` with the stored
  session resolving to the new org.
- The multi-org contract change surfaced one stale expectation (the
  older org lifecycle test asserted second-founding `409`); updated to
  `201` and the full HTTP suite passes in one run.

## Limits

- No routes mounted; invite TTL not caller-configurable over HTTP.
- No member list/removal endpoints, no invite listing or revocation
  endpoint, no audit trail; email transport still synthetic.
